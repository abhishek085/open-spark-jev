spark-s1 is an open System One decision model (release ids: spark-s1-<size>-<recipe>-v<n>). It is not TypeSafe's Jev. Probabilities come from a single forward pass over the option labels — treat confidence as a calibrated estimate only on task types like the ones it was trained on, and check it on your own data before relying on it.
